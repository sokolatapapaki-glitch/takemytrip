# Activity Modal — Restaurants / Notes / Related Activities Polish — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Polish the activity detail modal's Restaurants cards, Notes bars, and the Related Activities strip (hover feedback, happier note colours, a bigger renamed heading, and padding so hovered cards aren't clipped).

**Architecture:** All changes are Tailwind `className` edits inside a single client component, `app/components/ActivityDetail/index.tsx`. No new files, props, state, or dependencies. Each task swaps one exact class string for another.

**Tech Stack:** Next.js (App Router), Tailwind CSS v4, React. This repo has no component/unit test runner; verification is `npx tsc --noEmit -p tsconfig.json` (compiles clean = no JSX/type breakage) plus an explicit visual check in the running app.

**How to view the changes:** Run `npm run dev`, open any city's activities (e.g. `/activities`), click a card's **See more** to open the modal. The Restaurants, Notes, and Related Activities sections live in the modal's right column / lower strip. Pick an activity that actually has restaurants and notes (most do).

### Task 4: Related Activities strip — top padding so hovered cards aren't clipped

**Files:**
- Modify: `app/components/ActivityDetail/index.tsx` (the horizontal strip container `<div>`, currently ~line 479)

**What & why:** The strip is `overflow-x-auto`, which makes the browser clip vertical overflow too. On hover each card does `hover:-translate-y-1 hover:rotate-1` (defined in `app/activities/components/ActivityCard.tsx`), lifting/tilting its top edge above the container's content box — so the top gets cut off. Adding vertical padding inside the scroll container expands the content box, so the lifted/tilted card stays within the padded area and is fully visible. (Padding is the right fix here, not `overflow-visible`, because the strip must keep its horizontal scroll.)

- [ ] **Step 1: Add vertical padding to the strip**

Find this exact element (the horizontal scroller wrapping the related cards):

```tsx
          <div className={`mt-3 flex gap-4 overflow-x-auto pb-2 ${hoverScrollbar}`}>
```

Replace its className (`pb-2` → `py-3`, giving ~12px top room for the ~6px hover lift+tilt):

```tsx
          <div className={`mt-3 flex gap-4 overflow-x-auto py-3 ${hoverScrollbar}`}>
```

- [ ] **Step 2: Typecheck**

Run: `npx tsc --noEmit -p tsconfig.json`
Expected: no output (exit 0).

- [ ] **Step 3: Visual check**

Hover a card in the Related Activities strip: it lifts and tilts and is **fully visible** — no clipping of its top edge. Horizontal scrolling of the strip still works, and no new vertical scrollbar appears. If any clipping remains on the most-tilted card, bump `py-3` to `py-4`.

- [ ] **Step 4: Commit**

```bash
git add app/components/ActivityDetail/index.tsx
git commit -m "fix: pad related-activities strip so hovered cards aren't clipped"
```
